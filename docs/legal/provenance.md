# Source Provenance Policy

Kesharon is licensed under Apache-2.0.

Contributors may use original work and dependencies or references whose licenses
are compatible with this repository. Reused code must retain required notices,
and significant architectural borrowing must be documented.

Do not use leaked, accidentally exposed, proprietary, source-available, or
otherwise unlicensed implementation material. In particular, leaked Claude Code
source is not an acceptable reference. Reimplement behavior only from public
documentation, public interfaces, and independently developed designs.

Every dependency introduced into a distributed artifact must have its license
and source recorded by the release SBOM process.
